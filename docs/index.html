Những điều cần biết

Tóm tắt kỹ thuật#

Mục Giá trị
Backend Python 3.10+, FastAPI + Uvicorn, SQLite (file data/contracts.db)
OCR / ảnh RapidOCR (onnxruntime), OpenCV, Pillow, zxing-cpp (đọc mã vạch/QR)
Frontend HTML + CSS + JavaScript thuần (không framework, không bước build)
Giao diện Phong cách iOS (màu chủ đạo #007AFF), 2 chế độ: điện thoại (<1000px, thanh tab dưới) và máy tính (≥1000px, thanh bên)
Kết nối điện thoại Tunnel Cloudflare (https, để dùng được camera); điện thoại phải nhập PIN
In Máy chủ vẽ ảnh A5 300dpi rồi in qua driver hệ điều hành (hoặc ESC/P2 qua mạng, chưa thử máy thật)
Hệ điều hành macOS, Windows (Linux chạy được theo script .sh)
Dữ liệu cá nhân Ảnh CCCD/cà vẹt lưu file cục bộ, tự xóa sau N ngày khi hợp đồng đóng; không đưa lên Git

Điểm cần biết ngay (người mới tiếp quản)#

  1. Mọi dữ liệu nằm trong thư mục data/ (contracts.db, anh/, backup/, settings.json). Sao lưu thư mục này là đủ. Thư mục này không nằm trong Git.
  2. Điện thoại chỉ thấy hợp đồng khi đã nhập PIN. Chưa đặt PIN thì điện thoại không xem được gì — đặt PIN ở Cài đặt trên máy tính của tiệm.
  3. Việc nhạy cảm (sửa, hủy, mở lại, xóa hẳn, báo cáo tiền, sao lưu) chỉ làm được trên chính máy chạy server, không làm được qua link công khai.
  4. Lệnh in nằm trong RAM, mất khi khởi động lại server (hợp đồng thì đã lưu trong database).
  5. Tọa độ mẫu in backend/template.json là ước lượng ("calibrated": false) — cần đo lại với tờ giấy mẫu thật khi in chính thức.
