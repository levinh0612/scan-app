Tài liệu 05

Vận hành và cài đặt

Dành cho người quản trị máy chạy server. Bản cài đặt tóm tắt cũng có ở ../README.md.

⏱ 8 phút đọc👤 Quản trị máy

1. Yêu cầu#

Hạng mục Yêu cầu
Máy chủ Máy tính luôn bật ở tiệm (macOS đã thử; Windows 10/11 chưa thử trên máy thật); nên đặt IP cố định trong router, tắt chế độ ngủ
Phần mềm Git, Python ≥ 3.10 (script tự cài/kiểm tra), cloudflared (tunnel https, script tự cài trên Windows)
Mạng Internet để dùng link https cho điện thoại (không cần nếu chỉ dùng trên máy chủ)
Máy in Máy in có driver trên máy chủ, khổ A5 (phun/laser/kim); đặt làm máy in mặc định
Điện thoại Trình duyệt hiện đại (Safari iOS / Chrome Android), cấp quyền camera
Thư viện Python rapidocr-onnxruntime, opencv-python-headless, fastapi, uvicorn[standard], python-multipart, pillow, numpy, zxing-cpp, segno, cryptography (backend/requirements.txt)

2. Cài đặt lần đầu#

  1. Lấy mã nguồn: git clone https://github.com/levinh0612/scan-app.git
  2. Bấm đúp một file: - macOS: RUN_THIS_FILE_MACOS.command (tạo biểu tượng ScanApp, cần Xcode Command Line Tools) - Windows: RUN_THIS_FILE_WIN.cmd (chọn Yes khi hỏi quyền; cài môi trường, cloudflared, mở tường lửa, tạo tác vụ nền ScanApp và ScanApp-Update)
  3. Mở biểu tượng ScanApp → chờ khi hiện mã QR + link → Mở app trên máy này.
  4. Đặt PIN: Cài đặt → Mã PIN → nhập 4–6 số → Lưu. Nếu không đặt, điện thoại không xem được hợp đồng.
  5. Thêm máy in vào hệ điều hành, đặt làm mặc định. In thử một hợp đồng thử, hiệu chỉnh tọa độ (§6).
  6. Cài đặt → Mặc định khi lập / gia hạn: số ngày kỳ, lệ phí kỳ; số ngày giữ ảnh.
  7. Dọn hồ sơ thử bằng Xóa hẳn hồ sơ (chỉ máy chủ).

3. Chạy và dừng#

Việc macOS / Linux Windows
Cài + cập nhật + chạy ./scripts/run.sh powershell -File scripts\run.ps1
Không kéo code mới ./scripts/run.sh --no-pull … run.ps1 -NoPull
Chế độ tự động (restart khi có code mới) --auto -Auto
Bật/tắt tunnel https --tunnel / --no-tunnel -Tunnel
https tự ký trong wifi --https -Https
Đổi cổng PORT=9000 ./scripts/run.sh $env:PORT=9000; … run.ps1
Dừng ./scripts/stop.sh (giữ tunnel: --keep-tunnel) powershell -File scripts\stop.ps1

Cổng mặc định 8000; bận thì tự chọn cổng trống kế tiếp (ghi ở .run/port).

4 bước của run: (B1) cài tài nguyên → (B2) git pull --ff-only → (B3) kiểm tra: biên dịch, chạy test nếu có, thử import app — lỗi thì hoàn tác code, không đụng server đang chạy → (B4) start/restart, chờ /api/health tối đa 30 giây, không lên thì quay về bản cũ.

Lưu ý

Sau khi sửa mã backend phải restart server mới có hiệu lực. Frontend là file tĩnh — chỉ cần tải lại trang (Ctrl/Cmd+R; điện thoại: đóng và mở lại).

4. Tệp và thư mục cần biết#

Đường dẫn Mục đích Sao lưu?
data/contracts.db CSDL chính Có
data/anh/ Ảnh giấy tờ Có (nếu muốn giữ)
data/settings.json Cài đặt + PIN băm Có
data/backup/ Bản sao lưu tự động (30 ngày) Là bản sao lưu
data/offsite.json Thư mục sao lưu ngoài Có
.run/ pid, cổng, cấu hình in print.json Chỉ print.json
logs/server.log, server.err.log, tunnel.log, launcher.log, install.log Nhật ký Không

Chuyển sang máy mới: cài ScanApp như §2, dừng server, chép nguyên data/ và .run/print.json sang, chạy lại.

5. Sao lưu và khôi phục#

Tự động: mỗi ngày 1 bản + ngay sau mỗi thay đổi → data/backup/contracts-YYYYMMDD.db, giữ 30 bản. Có thể đặt thư mục sao lưu ngoài (USB, Google Drive for desktop, ổ mạng) để mỗi bản được chép thêm sang đó.

Thủ công: Cài đặt → Sao lưu tự động → Sao lưu ngay / Tải bản sao lưu về máy.

Khôi phục (khi sửa/xóa nhầm): 1. Cài đặt → Sao lưu → chọn bản (theo ngày) → Khôi phục. 2. App tự lưu bản hiện tại thành truoc-khoi-phuc-<thời gian>.db (giữ 5 bản) rồi mới ghi đè — có thể quay lại nếu chọn nhầm. 3. Nếu không vào được giao diện: dừng server, chép file contracts-YYYYMMDD.db đè lên data/contracts.db (xóa contracts.db-wal/-shm nếu có), chạy lại.

Khuyến nghị: mỗi tuần tải một bản về USB/Drive; bản trong máy mất cùng máy. Ảnh trong data/anh/ không được sao lưu tự động.

6. Cấu hình in#

File .run/print.json (tạo khi cần, không có sẵn cũng chạy được):

{"printer": "Tên máy in", "mode": "driver", "dx": 0, "dy": 0}
Khóa Ý nghĩa
printer Tên máy in; bỏ trống = máy in mặc định của OS
mode driver (mặc định, mọi máy in có driver) hoặc escp (máy kim có card mạng)
host, port Chỉ cho escp (cổng mặc định 9100)
dx, dy Bù lệch cơ học (mm); thử với số nhỏ rồi in lại để biết chiều dịch

Hiệu chỉnh tọa độ: tọa độ nằm ở backend/template.json (mm từ góc trên-trái khổ 148×210; y là đường chữ). Hiện đang đánh dấu "calibrated": false (ước lượng từ ảnh chụp nghiêng). Quy trình: 1. Đặt tờ giấy mẫu thật vào khay; in hợp đồng thử. 2. Đo độ lệch từng ô (hoặc dùng dx/dy nếu lệch đều). 3. Sửa x, y, w, size trong template.json, restart server, in lại tới khi khớp, rồi đặt "calibrated": true. 4. Xem trước ảnh sẽ in ở /api/jobs/<id>/preview.png (cần PIN nếu qua link công khai).

Trạng thái in đọc từ hàng đợi thật của OS: Đang in → Đã gửi máy in; hết giấy/mất wifi quá 2 phút → Lỗi + lý do, lệnh bị hủy để in lại không bị in đôi.

7. Bảo mật vận hành#

  • Đặt PIN ngay khi cài; đổi PIN khi nhân viên nghỉ việc (đổi PIN = đăng xuất mọi điện thoại).
  • Link tunnel công khai; chỉ chia sẻ cho nhân viên. Link đổi mỗi lần chạy lại.
  • Server mặc định nghe mọi giao diện mạng; trong mạng không tin cậy hãy chặn cổng 8000 từ LAN bằng tường lửa nếu chỉ dùng tunnel.
  • Không bật SCAN_DEBUG=1 trong vận hành thường ngày (ghi chữ gốc có dữ liệu cá nhân); nếu bật để dò lỗi, xóa log sau khi dùng.
  • Ảnh CCCD là dữ liệu cá nhân (Nghị định 13/2023): giữ ảnh ngắn nhất có thể (Cài đặt → số ngày giữ), mã hóa ổ đĩa máy chủ nếu có thể.
  • Không đưa data/, *.jpg, .env lên Git (đã có trong .gitignore).

9. Cập nhật phiên bản#

  • Windows: tác vụ ScanApp-Update kéo code mới mỗi 30 phút, kiểm tra, restart giữ nguyên link; lỗi thì tự quay về bản cũ; có lệnh in chờ thì hoãn.
  • macOS/Linux: chạy ./scripts/run.sh khi muốn cập nhật; hoặc --auto trong tác vụ định kỳ.
  • Lược đồ CSDL tự khởi tạo (CREATE … IF NOT EXISTS) mỗi lần kết nối. Cột thêm về sau (ten_k, nguon) được bổ sung bằng kiểm tra PRAGMA table_info + ALTER TABLE ADD COLUMN trong contracts.connect(). Chưa có hệ thống migration có số phiên bản — khi thêm cột mới hãy làm theo cùng mẫu đó, và sao lưu trước khi nâng cấp.
